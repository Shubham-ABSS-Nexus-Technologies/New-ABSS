# src

Future source folder for frontend code.

Suggested layout:

- `pages/` - public page source
- `admin/` - admin page source
- `components/` - shared HTML/UI pieces
- `styles/` - split CSS files
- `scripts/` - browser JavaScript modules
- `config/` - frontend config
- `services/` - frontend data/auth services

Current live files remain in the project root until migration is completed.
